工信部 NVDB 提示：防范 OpenJDK 缓冲区溢出高危漏洞
11 月 23 日，工业和信息化部网络安全威胁和漏洞信息共享平台（NVDB）发布提示，监测发现，OpenJDK 存在缓冲区溢出高危漏洞，危害严重。OpenJDK 是 Java 平台标准版（Java SE）的开源实现，由甲骨文（Oracle）公司主导维护，Oracle Java SE、Oracle GraalVM 等产品均基于其源代码构建。由于其 Base64 解码器存在堆缓冲区溢出缺陷，攻击者可通过发送恶意数据损坏内存，造成内存敏感信息泄露或远程执行任意代码。受影响产品包括 OpenJDK 及 Oracle Java SE、Oracle GraalVM for JDK、Oracle GraalVM Enterprise Edition、Red Hat OpenJDK、Amazon Corretto 等基于其源代码构建的发行版。目前，OpenJDK 社区及部分发行版厂商已修复漏洞并发布安全公告。建议相关单位和用户立即开展全面排查，及时升级至最新安全版本，或采取关闭 Base64 解码加速路径、限制虚拟机 AVX-512 指令集使用、收敛互联网暴露面、加强网络访问控制等临时防护措施，消除网络安全隐患。
