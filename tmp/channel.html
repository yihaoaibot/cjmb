OpenAI 自动化漏洞链路发现 1724 个 Linux 内核漏洞
OpenAI 自动化漏洞研究链路共识别出 2308 个 Linux 内核漏洞候选样本，通过动态复现确认 1724 个漏洞，并生成 948 个本地提权（LPE）利用程序，这类漏洞可让无权限用户获取 root 最高权限。该链路分为五个阶段：漏洞发现、动态验证、可利用性评估、补丁生成、人工复核。第二次扫描的全流程成本约 121 万美元 API 点数，产出 948 个独立本地提权漏洞。若按漏洞赏金标准估算，这 948 个利用程序价值区间为 1890 万至 6630 万美元，是链路成本的 16 至 55 倍。智能体使用了 10 种全新漏洞利用技术，已经第三方内核漏洞专家核验确认为新方法。OpenAI 正向 Linux 内核维护人员提交漏洞信息与对应补丁。
