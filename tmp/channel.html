Meta 推出具备“前沿”功能的人工智能模型 Muse Wonder
Meta 发布名为 Muse Wonder 的全新人工智能模型，公司称该模型较前代产品实现重大跃升。其内部代号为 “Watermelon”。据称该模型具备 “前沿能力”，在代码编写、处理金融与法律问题等领域，可对标 OpenAI 的 ChatGPT 以及 Anthropic 的 Claude 等顶尖模型。开发者可通过 Meta 模型 API 与 Muse Code 调用 Muse Wonder，该模型不久后将为 Meta 个人 AI 助手 Muse 的订阅版提供底层支持。Meta AI 负责人 Alexandr Wang 周一在采访中表示：“这是真正的前沿模型。我们坚信它能与市面上最优模型竞争，尤其在个人及专业智能代理任务上达到顶尖水平。” 对于质疑 Meta 打造出尖端模型的声音，Wang 称：“我建议大家亲自试用，自行评判。”
