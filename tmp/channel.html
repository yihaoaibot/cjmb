OpenAI：明天将调整 200 美元 Pro 订阅的用量计算方式
OpenAI Codex 产品负责人：明天将重新向新用户开放月费 200 美元的 Pro 订阅，但同时也将调整该订阅的用量计算方式。与原来的月费 200 美元 Pro 方案相比，新方案对应的 API 支出金额将只有原来的一半。该负责人解释到，之所以推出如此措施，是因为不想在其他方面妥协，并承诺不再重新引入 5 小时限制，这样用户就可以在需要时充分利用每周的使用量。在订阅服务中，我们保证随着时间推移，你总能完成更多工作，并且质量水平不断提升。这意味着，由于模型效率的提高以及我们通过降低 API 价格将这些改进传递给你，你将持续获得每美元更高的价值。他还表示，明天还会为订阅增加更多不会计入用量的功能。暂时不会透露具体是什么。

姆巴佩受伤加上增长放缓，杰富瑞继续看空昂跑
杰富瑞在姆巴佩穿着昂跑原型足球鞋比赛时膝部受伤后，维持昂跑“跑输大盘”评级和 20 美元目标价。姆巴佩本月刚与昂跑签约成为全球品牌大使及股权合作伙伴，但目前没有医学证据表明此次伤病与球鞋有关。杰富瑞认为，公司更值得关注的问题仍是增长放缓：过去六个季度整体营收增速已由 36%降至 13%，美洲业务增速仅 4%，批发渠道增速为 5%，同时库存增速约为销售增速的两倍。该机构指出，在增长动能减弱之际，公司进军足球还将增加运动员签约、市场推广和产品投入成本，因此认为这一扩张更像是为支撑新设定的长期增长目标，而非建立在已经验证的产品优势之上。杰富瑞对昂跑 2027 年 EBITDA 的预测也明显低于市场共识。

英媒：美国企业加速转向“开放权重”AI 模型
据英国《金融时报》28 日报道，随着信息技术开支的不断攀升，美国企业界加速转向成本更低的“开放权重”人工智能（AI）模型，高管们正在寻找 Anthropic 和 OpenAI 模型的替代方案。报道援引研究平台 AlphaSense 的数据表示，在 8 月和 9 月的企业财报电话会议和投资者会议上，高管们提及“开放权重”或“开源”模型的次数较去年同期激增 6 倍。 所谓“开放权重”模型，是指用户可以对其进行定制，并在自己的硬件上运行的模型。对于企业而言，运行这类模型的成本相对更低。《金融时报》表示，上述变化在科技企业中最为明显，不过，包括美国 PNC 金融服务集团、物流企业罗宾逊全球货运和工业巨头西门子在内的多个跨行业企业，近几周也都讨论了使用开放权重模型。 （环球网）
