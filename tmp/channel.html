山西省朔州市委原常委、秘书长何向荣被“双开”
中央纪委国家监委网站 7 月 18 日通报，据山西省纪委监委消息：日前，经山西省委批准，山西省纪委监委对朔州市委原常委、秘书长何向荣严重违纪违法问题进行了立案审查调查。经查，何向荣理想信念丧失，纪法底线失守，搞迷信活动；无视中央八项规定精神，收受礼品、礼金，接受可能影响公正执行公务的宴请；违背组织原则，在职务调整中为他人谋取利益并收受财物；不正确履职，违规为有关企业融资，造成国有资金损失风险；利用职务便利，为他人在业务承揽、款项结算等方面谋取利益，并非法收受巨额财物。何向荣严重违反党的政治纪律、组织纪律、廉洁纪律、工作纪律，构成严重职务违法并涉嫌受贿犯罪，且在党的十八大后不收敛、不收手，性质严重，影响恶劣，应予严肃处理。依据《中国共产党纪律处分条例》《中华人民共和国监察法》《中华人民共和国公职人员政务处分法》等有关规定，经山西省纪委常委会会议研究并报山西省委批准，决定给予何向荣开除党籍处分；由省监委给予其开除公职处分；收缴其违纪违法所得；将其涉嫌犯罪问题移送检察机关依法审查起诉，所涉财物一并移送。

阿里与荣耀共创面向手机场景的解决方案，已落地 Robot Phone
7 月 18 日，在 WAIC 2026“从数字屏幕到具身智能，开启物理世界新范式”分论坛，阿里巴巴宣布联合荣耀，基于“千问大模型”共创面向手机场景深度优化的解决方案，已在荣耀的 Robot Phone 落地。未来的手机 Agent，核心问题是完成复杂长程任务，比如“预订下周三上海参加智造大会的行程”，看似日常，但对于手机 Agent 来说并不容易。Agent 需先结合用户偏好，订车程短的靠窗二等座高铁票、挑选离会场最近的酒店；如果车票售罄，Agent 需重新规划，切换到临近的车次；用户上传大会日程表的照片后，Agent 需看懂图片、扫描二维码、填写表单报名。全程涉及意图补全、记忆注入、skill 调用、异常恢复和多工具复杂操作等，任何一个环节不稳健，都会导致任务失败。阿里巴巴集团副总裁、ATH 事业群 Token Foundry 多模态交互负责人许主洪博士在圆桌论坛中表示，在手机 Agent 火热的当下，最需要做的“第一件事”，正是找到一个高频、有价值的真实场景，构建模型-Harness 工程-真实场景反馈的 Agent 闭环，让模型被大量用户真正用起来。（硬 AI）
