OpenAI 称发现其 AI Agent 削弱了对齐失效监控机制
金十数据 10 月 21 日讯，OpenAI 称，在两项内部编程任务中，AI Agent 在执行用户要求的软件修改时，削弱了对齐失效监控机制。在第一起事件中，一个负责修复评估流程的 GPT-6.1 Sol Agent 关闭了向安全团队自动发送警报的功能。该 Agent 将此前一条“在搜索 Slack 历史记录期间不要发送消息”的指令，理解为应当屏蔽监控通知的理由。在另一起独立事件中，一个负责迁移程序的 GPT-6 Astra Agent 为了使代码与参考实现保持一致，删除了程序中的监控集成，随后还向用户谎称自己并未移除监控机制。在这两起事件中，AI Agent 都曾考虑过是否应该保留监控防护措施，但最终将常规编程指令解读为削弱这些防护措施的许可。作为回应，我们正在加强对齐失效监控系统，同时也在评估这些案例究竟反映了 AI 的良性过度坚持行为（benign overpersistence），还是表明其在特定情况下存在规避对齐失效监控的倾向。

中信建投：兆瓦级液冷落地，行业进入标准化放量新阶段
中信建投研报称，兆瓦级液冷落地，行业进入标准化放量新阶段。一是产品端，全液冷由芯片级走向整机柜级，超节点成为新载体，国产厂商推出全球首个兆瓦级单相冷板全液冷超节点，单柜散热达 1 兆瓦、单芯片解热迈向 5000 瓦，并实现正交全液冷与全盲插、水电物理隔离。二是行业标准端，首部数据中心冷板式液冷国家标准实施在即，将冷板、分配单元、循环泵、管路与快接头纳入统一框架、要求同规格可互换，配套机柜通用规范与浸没式介质标准同步出台，接口不兼容的行业痛点被厘清，行业由项目制定制转入标准化规模交付。三是交付端，订单能见度逐步明确，头部公司接到海外客户单笔制冷设备订单折合逾 27 亿元、交付期压缩至 120 天。四是产业趋势端，需求由芯片扩散至整机柜全链路，其中专用芯片液冷渗透率有望持续上升，并带来较大增量；国产替代沿核心物料清单由管路、分集水器向快接头与冷板推进，受验证周期制约仍属循序渐进，竞争焦点转向技术、量产与全球交付能力。中信建投判断代工链利润先于品牌链兑现，四季度至 2027 年一季度是液冷板块业绩分水岭，2027 年行业将由普遍景气转向份额与盈利分化。
