美国学者撰文批驳所谓“中国冲击”“中国挤压”论调 外交部回应
外交部发言人林剑主持例行记者会。有记者提问，我们注意到，近期美国哈佛大学肯尼迪学院教授达尼·罗德里克、美国企业研究所经济政策研究主任迈克尔·斯特雷恩等经济学家撰文批驳所谓“中国冲击”“中国挤压”论调，认为中国的贸易政策并非“以邻为壑”，而是“惠邻利邻”；中国不光卖成品，还大量出口生产设备、零部件、中间品，帮不少国家降低工业化成本；要求中国主动牺牲本国产业给别国让路，这种论调没有经济学道理。发言人对此有何评论？林剑表示，我们注意到，越来越多有识之士发表了类似见解。事实证明，中国发展带给世界的不是“冲击”而是机遇，不是“挤压”而是赋能。物美价优的中国制造，降低了发展中国家的工业化门槛；开源普惠的中国创新，让更多国家用得上、用得起前沿技术；稳定可靠的中国供应，提升了全球产供链的韧性，助推全球南方国家更快走上现代化道路。林剑说，面对当前世界经济不确定、不稳定性因素增多，中国愿继续以自身高质量发展，为各国提供更多市场红利、创新红利、发展红利。 (北京日报)

国产大模型掀涨价潮，“百模大战”熄火？
8 月 17 日 0 点起，DeepSeek-V4 API 新定价正式生效。此轮调整实行分时定价，高峰时段输出价格升至 27 元/百万 tokens，为此前价格的 4.5 倍；缓存未命中价格升至 9 元/百万 tokens，为此前价格的 3 倍；缓存命中价格则大幅上调至 0.30 元/百万 tokens，为此前价格的 12 倍。空闲时段价格则为高峰时段的一半。 涨价后，DeepSeek 告别了曾经的“极致性价比”路线。有业内人士告诉记者，此前智谱的模型相对较贵，因为它能很好地解决 coding 问题；DeepSeek 主打性价比，特别是很多 24 小时运作的智能体，其消耗的 token 数量极其巨大，开发者往往会选择 DeepSeek 模型。但 DeepSeek 涨价，并非孤例。过去数月，智谱、Kimi、MiniMax 等国产大模型也相继对部分 API 价格进行了上调。“这轮调价不是全行业统一涨价，而是独立模型厂商领涨，自有算力的大厂按兵不动或变相调价。”致同咨询交易支持服务合伙人梁伟告诉 21 世纪经济报道记者，今年以来智谱、月之暗面、DeepSeek 等独立厂商相继上调 API 定价，阿里、字节、腾讯等大厂则按兵不动。

联昌国际：印尼央行或将于第四季度加息
金十数据 8 月 20 日讯，联昌国际银行经济学家在一份报告中指出，如果外部风险和通胀风险再次对印尼盾构成压力，印尼央行可能在第四季度加息 25 个基点。他们表示，经常账户赤字的收窄可能在下半年支撑印尼盾，但包括美联储利率路径、美元走强和油价在内的外部因素仍可能是影响印尼盾汇率的关键因素。他们认为，受厄尔尼诺现象可能导致的粮食短缺和中东地区能源价格波动的影响，印尼国内通胀风险偏向上行。鉴于预计下半年经济增长将放缓，联昌国际银行预计印尼央行将保持耐心，同时密切关注全球利率和印尼盾的走势。
