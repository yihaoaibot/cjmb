工信部 NVDB 提示：防范 NGINX 堆缓冲区溢出高危漏洞
近日，工业和信息化部网络安全威胁和漏洞信息共享平台（NVDB）监测发现，NGINX 存在堆缓冲区溢出高危漏洞，危害严重。NGINX 是美国 F5 公司维护的开源 Web 服务器与反向代理软件，广泛用于 Web 服务部署、负载均衡及邮件代理等场景。由于其处理 HTTP/2 协议流量控制窗口时存在设计缺陷，攻击者可通过向启用 HTTP/2 协议的服务器发送特制流量，导致堆缓冲区溢出，甚至可能造成服务崩溃、内存破坏或远程代码执行等危害。受影响版本包括：NGINX 开源版 1.9.5≤ver≤1.30.6、1.31.0≤ver≤1.31.8；NGINX Plus 37.0.0≤ver≤37.0.7.1、37.1.0≤ver≤37.2.0.1、R34≤ver≤R36；部分内嵌 NGINX 核心组件产品（如 NGINX Instance Manager、NGINX Ingress Controller 等）也受该漏洞影响。目前，F5 公司已修复漏洞并发布安全公告（URL 链接：https://my.f5.com/manage/s/article/K000163926）。建议相关单位和用户立即开展全面排查，及时升级至最新安全版本，消除网络安全隐患。
